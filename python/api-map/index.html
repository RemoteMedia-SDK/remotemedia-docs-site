    Python API map¶

    This is a task index for the reviewed checkout. Follow each guide for prerequisites and lifecycle, and the API reference for core signatures, return values, ownership, errors, and release differences. Advanced operations remain source-reviewed unless their guide records a run.

    Task Import or object Entry points Guide
    Detect the native runtime remotemedia is_rust_runtime_available(), get_rust_runtime() Install
    Execute a manifest or supported instance input remotemedia execute_pipeline(), execute_pipeline_with_input() FFI
    Compose Python objects remotemedia Pipeline, Node; run(), serialize(), managed_execution() Overview
    Create a native stream remotemedia.runtime create_streaming_session() Streaming
    Send/receive/finish Streaming session send_input(), recv_output(), recv_event(), signal_input_complete(), close() Streaming
    Share a native session remotemedia.runtime create_shared_streaming_session() Shared sessions
    Inspect copy accounting Streaming session input_copy_report(), node_copy_reports() Streaming
    Attach control remotemedia.control attach(), attach_inproc(), AttachedSession Scaling
    Tap/inject/intercept Attached session subscribe(), subscribe_in(), publish(), publish_out(), intercept() Control
    Override node state remotemedia.control.NodeState; attached session set_node_state(), clear_node_state() Control
    Construct control payloads remotemedia.control.Data from_text(), from_json(), with_metadata() Control
    Expose and call RPC remotemedia.rpc.rpc; attached session @rpc(...), ctrl.<node_id>.<method>(...) RPC
    Host application endpoints Attached session host_endpoint(), has_endpoint(), endpoints() RPC
    Implement a worker node remotemedia.core.multiprocessing MultiprocessNode, NodeConfig, register_node Nodes
    Read/write worker payloads remotemedia.core.multiprocessing.data RuntimeData and modality metadata Nodes
    Implement cancellable generation remotemedia.core.cancel GeneratorNode, modality mixins, cancellation types Cancellation
    Load a source plugin Pipeline manifest plugins, plugin.toml Source plugins
    Host application tools Control attach host_endpoint(), EndpointCall.reply() RPC/tools
    Inspect copy/performance data Session and control attach input_copy_report(), node_copy_reports(), __perf__.out Observability

    remotemedia.control.Data and worker RuntimeData serve different boundaries. Do not interchange them based on similar method names.

    Scaling pipeline deployment and member admission are currently documented as HTTP/signaling operations. The older RemoteExecutionClient and RemoteExecutorConfig names in the Python tree are a separate remote-execution surface; they are not evidence of a dedicated Scaling client.
